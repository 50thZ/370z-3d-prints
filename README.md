# 370Z 3D Prints

Open-source, 3D-printable parts for the Nissan 370Z, designed by **50th Z**.
Print-ready 3MF/STL files are included, along with editable source files (STEP, Fusion) where available, so you can modify any part for your own build.

> **Status:** early release. Fitment, material, and print-setting notes are still being filled in. Entries marked **TBD** are not yet confirmed. Please report what you find (see [Contributing](#contributing)).

## Parts

| Part | Folder | Print-ready | Source |
|---|---|---|---|
| Radio bezel | [`parts/radio-bezel`](parts/radio-bezel) | 3MF, STL | TBD |
| Storage box (hinge box, aftermarket bezel) | [`parts/storage-box`](parts/storage-box) | 3MF, STL (hinge box, curved-door hinge box) | STEP (all variants: hinge box, curved door, flat door with and without Z, open box) |
| Side skirt T-slot bracket | [`parts/side-skirt-tslot-bracket`](parts/side-skirt-tslot-bracket) | STL | STEP |
| Wheel center caps (Rays factory wheels) | [`parts/wheel-center-caps`](parts/wheel-center-caps) | 3MF, STL (plain and Z-emblem versions) | STEP |

Each part folder also has preview renders (JPEG) and, where available, photos of the real printed and installed part. The flat-door and open-box storage box variants are STEP source only for now; a print-ready export is TBD.

Fitment (model years/trim), recommended material, and print settings for each part: **TBD**. Interior and engine-bay parts can see high cabin temperatures, so use a heat-resistant filament such as ASA or PETG rather than PLA unless noted otherwise.
